What this integration runs

Public Git snapshot → ResearchLedger ingestion → SQLite and BM25 retrieval → source excerpts → deterministic citation, number and quote checks. Generated mode adds one bounded Gemini generation request and one independent support-check request. It uses no Vertex AI, BigQuery, paid embeddings or hosted vector database.

Evidence limits: keyword relevance is not proof that a passage answers your question. Exact-excerpt mode does not perform semantic verification. Model support checks can be wrong. An injected test claim is invented, visibly separated and excluded from the answer.

Generated mode sends your question and retrieved public excerpts to Google. Use public research questions only. API keys remain on the server; no keys are requested or stored by this browser.
